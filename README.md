# 📝 To-Do List

A simple **To-Do List web application** built using **Java and Spring Boot**.
This project is created as a beginner-friendly project to learn Spring Boot, REST APIs, and backend development.

## 🚀 Features

* ➕ Add a new task
* 📋 View all tasks
* ✏️ Update a task
* 🗑️ Delete a task
* ✅ Mark tasks as completed

## 🛠️ Technologies Used

* **Java**
* **Spring Boot**
* **Spring Web**
* **Maven**
* **Git & GitHub**

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/maheksingh16/To-do-list.git
```

### 2. Open the project

Open the project in **IntelliJ IDEA** or any IDE that supports Java and Maven.

### 3. Run the application

Run:

```text
ToDoListApplication.java
```

The Spring Boot application will start on:

```text
http://localhost:8080
```
